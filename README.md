# No more HM slaves!

**The goal of this mod is to enhance immersion by letting Pokemon use Field Moves naturally, not only by learning the HM or TM.**
Like, you wanna surf? Just get on your Lapras. You wanna cut a bush? Scyther literally has blades for arms. Wanna light up a cave? Charmander has a flame on it's tail!

> HM Moves can be used without teaching the HM to some species.
The **badge is still a requirement** to use the move outside of battle.
TMs and HMs still work like they used to. If you teach HM01 CUT to a species, it can use it. Yes, this will let you skip the SS Anne.
To create an immersive feel, field moves are tied to different factors:

# Main Changes

* CUT can be used by any species with visible claws, blades or pincers.

* FLY can be used by ANY Flying types.

* SURF can be used by ANY Water types.

* STRENGTH can be used by ANY species that has an attack value of at least 55. (That is the attack value of a Lv. 25 Rhyhorn with 15 Attack IVs. We'll have to see if it's well balanced. I'm thinking of making only Rock and Ground types able to use the move naturally)

* FLASH can be used by Electric Types, species with visible flames or psychic abilities.

* TELEPORT can always be used by the ABRA line and Mewtwo and Mew

* DIG can always be used by the Diglett line.

See Lists of moves and which species can use it [here](https://github.com/AlfonsPistoletti/gen1recomp-mod-immersive-field-moves/tree/main/assets/move_whitelists).

# Known Issues
`SOFTBOILED` hasn't been touched yet. That move will work as in vanilla and appear at the top of the sub menu.
